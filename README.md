# Linguistics

We study language through explicit descriptions, models and useful
comparisons between approaches. This library brings together our
explanations, source routes and small computational resources.

Our shared human reference is the [Linguistics Wiki](https://github.com/JulTob/Linguistics/wiki).
Its first page introduces complementary models of language. Mathematical
linguistics is our initial collection; the library can grow with our
broader linguistic interests.

## Computational resources

We organise code by topic:

- `topics/normal-rewriting/`: ordered rewriting with an inspectable trace.
- `topics/information/`: probability and entropy with explicit units.
- `topics/coding/`: fixed-length binary words and error guarantees.

Each topic keeps its implementation and focused tests together. Human
explanations and their sources belong in the actual Wiki. Proposed Wiki
pages are reviewed separately before Julio incorporates them.

## Reference material

Our initial mathematical-linguistics source is Solomon Marcus, Edmond
Nicolau and Sorin Stati, _Introducción en la lingüística matemática_,
Spanish edition translated by Ramon Cerdá, Editorial Teide, 1978.
The book is retained privately for consultation. This repository
contains our original computational resources; it does not distribute
the book or its OCR text.
