# A corpus, a grammar and word uncertainty

We can use the same observations for two complementary models: one specifies which combinations we allow, and the other measures uncertainty about the identity of a sampled word.

We begin with this small corpus:

```text
red fox rests
blue fox sleeps
red hare sleeps
```

We treat spaces as word boundaries and each line as one sentence. Our corpus therefore contains three sentences, nine word tokens and six distinct word forms.

## We model possible combinations

For possible combinations, we first represent each sentence as an ordered triple:

```math
\begin{aligned}
C &= \{\text{red},\text{blue}\},\\
A &= \{\text{fox},\text{hare}\},\\
V &= \{\text{rests},\text{sleeps}\}.
\end{aligned}
```

The observed relation is

```math
R_{\mathrm{obs}}=
\{
(\text{red},\text{fox},\text{rests}),
(\text{blue},\text{fox},\text{sleeps}),
(\text{red},\text{hare},\text{sleeps})
\}.
```

Now we make a simple generalisation: every member of each category can combine with every member of the other two, in colour–animal–action order. The proposed relation is $R=C\times A\times V$, with $2\times2\times2=8$ combinations. Joining the three words gives the corresponding sentences.

| Colour | Animal | Action | Observed? |
| --- | --- | --- | --- |
| red | fox | rests | Yes |
| red | fox | sleeps | No |
| red | hare | rests | No |
| red | hare | sleeps | Yes |
| blue | fox | rests | No |
| blue | fox | sleeps | Yes |
| blue | hare | rests | No |
| blue | hare | sleeps | No |

An equivalent small grammar is:

```text
S      → Colour Animal Action
Colour → red | blue
Animal → fox | hare
Action → rests | sleeps
```

For example, it derives an unobserved combination:

```text
S
⇒ Colour Animal Action
⇒ blue Animal Action
⇒ blue hare Action
⇒ blue hare rests
```

The observations establish that three combinations occurred. They do not determine whether the five others are acceptable. A grammar listing exactly the three observed sentences also fits the evidence. Our product model adds a recombination assumption, and fixes the vocabulary and sentence length for this small task. It assigns no probabilities: allowing all eight combinations does not make them equally likely.

## We measure word uncertainty

For word uncertainty, we define a different experiment: choose one of the nine corpus positions uniformly, and let $W$ be the word form at that position. Thus $P(W=w)=n_w/9$. We sample _tokens_, so repeated words receive more probability than words occurring once.

Using base-two logarithms, the information of an outcome is $I(w)=-\log_2P(w)$, and its contribution to the average is $P(w)I(w)$:

| Word | Count $n_w$ | $P(w)$ | $I(w)$, bits | Contribution, bits |
| --- | ---: | ---: | ---: | ---: |
| red | 2 | $2/9$ | 2.169925 | 0.482206 |
| blue | 1 | $1/9$ | 3.169925 | 0.352214 |
| fox | 2 | $2/9$ | 2.169925 | 0.482206 |
| hare | 1 | $1/9$ | 3.169925 | 0.352214 |
| rests | 1 | $1/9$ | 3.169925 | 0.352214 |
| sleeps | 2 | $2/9$ | 2.169925 | 0.482206 |

The counts sum to nine and the probabilities sum to one. There are three words of each frequency, so the entropy is

```math
\begin{aligned}
H(W)
&= -\sum_w P(w)\log_2P(w)\\
&= -3\left(\frac29\log_2\frac29\right)
   -3\left(\frac19\log_2\frac19\right)\\
&= \log_2 9-\frac23\\
&\approx 2.503258\ \text{bits per sampled word token}.
\end{aligned}
```

For comparison, choosing uniformly among the six _word types_ would give $\log_2 6\approx2.584963$ bits. That is a different sampling experiment.

For our stated experiment, the corpus determines the distribution and entropy exactly. Treating these frequencies as probabilities for future speech would add a sampling and generalisation assumption. The calculation also discards word order and context: rearranging the nine tokens preserves this entropy while potentially destroying the sentence pattern. We have calculated uncertainty of one word identity, rather than a sentence entropy, an entropy rate or a measure of meaning. A probability model with positional or contextual dependencies could retain more structure.

## We check which rules are reachable

Does a recursive rule always make the generated language infinite? We examine a separate grammar with start symbol `S`, nonterminals `S` and `T`, terminals `x` and `y`, and these rules:

```text
S -> x
T -> yT | y
```

A generated language contains terminal strings derivable _from its designated start symbol_. Here, starting at $S$, the only derivation is

```math
S\Rightarrow x.
```

No rule reachable from $S$ introduces $T$. Consequently,

```math
L_S=\{x\}.
```

The recursive branch would generate infinitely many strings _if we started at $T$_:

```math
T\Rightarrow yT\Rightarrow\cdots\Rightarrow y^kT\Rightarrow y^{k+1},
\qquad k\geq0.
```

That branch has terminal growth and can terminate, but is unreachable from the specified start. Even reachable recursion alone is insufficient: $S\to S\mid x$ permits arbitrarily long derivations while generating only $x$. To establish infinitude, we need a repeatable mechanism accessible from the start that can finish in terminal strings with unbounded length; merely spotting a recursive rule does not establish that.
